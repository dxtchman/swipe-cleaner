# Swipe Cleaner

Tinder-style photo cleanup for Android. Swipe left to delete, swipe right to keep.

- **Screenshots**: everything in your Screenshots folder
- **Duplicates & similar**: exact copies anywhere in the gallery, plus near-identical shots taken within 10 minutes of each other (bursts). The best copy is shown in the corner as "Original".
- **All photos**: go through everything, newest first

Deleted photos go to the system trash (Android's own confirmation dialog appears first), and the last batch can be restored from the home screen. Photos you keep won't show up again.

## Install

Every push to `main` builds the app on GitHub Actions. Open **Releases**, tap the newest `SwipeCleaner.apk` and install it. Android will ask once to allow installs from your browser or GitHub app.

Requires Android 11 or newer.
